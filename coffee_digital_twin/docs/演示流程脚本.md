# 演示流程脚本

1. 打开微信小程序首页。
2. 进入建园初始化，保存咖啡园基础信息。
3. 进入农事打卡，录入一次灌溉或施肥。
4. 进入情景模拟，选择管理方案并运行三模型。
5. 进入模型结果页，展示 APSIM 产量、HYDRUS 水分、BEPS 生态指标。
6. 进入 AI 农技建议页，展示 what / how / why。
