# 咖啡数字孪生智能决策系统开发文档

本代码工程按原始 MVP 开发文档落地：

- `miniprogram/`：微信小程序前端，负责人蔡济远
- `backend/`：Flask 后端、SQLite、模型调度与融合，负责人蔡济远
- `server/`：本地服务器部署脚本与模型执行程序路径，负责人蔡济远
- `docs/`：接口、模型和答辩材料

MVP 主流程：

```text
建园初始化 -> 农事打卡 -> 情景模拟 -> Flask 调三模型 -> 结果融合 -> 小程序展示 -> AI农技建议
```

HYDRUS 与 BEPS 当前保留标准 adapter，占位输出字段与开发文档一致，后续可由各自负责人替换内部实现。
