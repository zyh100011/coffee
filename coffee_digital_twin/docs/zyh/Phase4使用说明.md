# Phase 4 使用说明

本阶段工程已实现T4.1–T4.5：确认式A/B接口、三步情景页、实时参数核验、错误码与恢复、真实冻结快照导入器和六步演示脚本。

重启后端后，在微信开发者工具编译本工程miniprogram。进入“情景”：选择地块与起始日期，额外灌溉0–100mm（快捷10/20/30），点下一步，阅读后端给出的基线和全部假设，确认后比较。模型只模拟7天水分响应；遮阴/追肥显示本期不支持。

成功时展示40cm双线、五深度第7天差值、湿润锋、吸水比、参数是否实际进入模型、未确定条件。可以打开双方证据，生成报告，或向助手发送“解释情景对比 <compare_id>”；助手通过白名单只读已有模型结果，不重新计算。

失败时不展示差值，保留输入供重试。回放恢复会重新显示确认页；当前历史假设案例仅0/20mm，原日期2026-09-01、原地块未知，不能改写为当前地块结果。原始模型版本、参数、日期和出处均可回查，报告同样标回放。

本机Windows live已通过HTTP核验，0/20mm差值与T2.2一致，保持live；没有修改EXE或APSIM/BEPS源码。72项pytest通过。用户的3个本地开发配置没有提交，也没有停止用户5000服务。

详见`演示流程.md`、`错误码与降级.md`、`scenario_phase4_verification.json`。H3/H4真实数据映射、H5真实服务、H8实际界面点击截图与真实六步演示待补；没有冻结空data-v1.0或伪造实测。
