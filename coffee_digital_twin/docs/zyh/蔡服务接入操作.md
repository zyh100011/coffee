## 地址与令牌拿到后

在 `coffee_digital_twin/backend/.env` 本地配置：

```dotenv
# 替换为蔡确认的、此电脑可达的业务API根地址；下面是占位，不能原样使用。
EVIDENCE_SERVICE_URL=http://<可达主机>:<业务端口>
EVIDENCE_API_TOKEN=<私下取得的访问令牌>
```

不用把.env发给其他人。模型原生18766接口不能替代业务接口。更改配置后重新启动后端；已有进程不会自动重读环境变量。

在工程目录用PowerShell检查：

```powershell
Set-Location 'E:\coffe model\coffee_competition_zyh\coffee_digital_twin'
.\.venv\Scripts\python.exe .\backend\tools\check_evidence_connection.py
.\.venv\Scripts\python.exe .\backend\tools\check_evidence_connection.py --check-auth
```

第一条只查健康状态；第二条额外发送一条固定农技路由请求，验证POST认证和响应契约，不执行农事工具。输出不含令牌或完整响应。`mock=true` 表示测试服务；不能作为真实联调通过。health成功也不等于POST认证成功或知识回答正确。
