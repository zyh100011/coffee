# 操作手册（2026-10-28）

当前入口是 coffee_digital_twin；数据库含一个卡蒂姆基地。界面修正和本地数据冻结已完成；蔡济远真实服务、微信截图、另一台电脑验收和录屏仍需分别完成，不把本地自动测试作为这几项验收。

## 环境要求

Windows 10/11、Python 3.11（安装时启用 py 启动器）、PowerShell、微信开发者工具。后端依赖使用 backend/requirements.lock.txt；小程序不需要 npm。实时模拟需要合法取得的 HYDRUS 引擎；未确认再分发许可前不把 EXE 随代码包共享。没有引擎可使用既有历史回放。

## 安装

在 coffee_digital_twin 目录打开 PowerShell：

```powershell
.\server\setup_windows.ps1
```

脚本创建 .venv、安装固定依赖，在 .env 不存在时复制模板，初始化数据库并导入已核验快照，然后运行自检。已有非空数据库不覆盖；不合格时停止并保留原库。已有环境可加 `-SkipDependencyInstall`；首次安装不要跳过依赖。

如果执行策略不允许运行本地脚本，可在当前 PowerShell 进程执行 `Set-ExecutionPolicy -Scope Process Bypass` 后重试；不修改全局执行策略。不要使用“以管理员身份运行”来掩盖数据或路径错误。

## 配置 .env

用本机编辑器打开 backend/.env。设置蔡提供的可达 EVIDENCE_SERVICE_URL 和 EVIDENCE_API_TOKEN；令牌仅留在后端，不能放进小程序、聊天、截图或 Git。另一台电脑的 127.0.0.1 不是本机可达地址。

DATA_VERSION 使用 data-v1.0；HYDRUS_MODE 使用 live（有合法引擎）或 replay（历史回放）；ALLOW_DEMO_FALLBACK=0、FLASK_DEBUG=0。更换目录时留空 COFFEE_DB_PATH/COFFEE_RUNTIME_DIR 使用工程默认值；不要沿用别人的绝对路径。已有 .env 只补数据版本空项，脚本不覆盖服务地址或令牌。

连接检查：在 backend 运行 `..\.venv\Scripts\python.exe tools/check_evidence_connection.py --check-auth`。只有真实服务成功且返回非mock，才能继续真实K/D/M/F联调。

## 导入数据

数据库不在源码Git包里，需另交：

- `server/backup/frozen/data-v1.0.db`：核验过的冻结快照。
- 仓库 `实验资料/03_地块与监测数据/raw`：32个匹配原始文件（31个CSV及土壤检测PDF），不得修改原值。
- 仓库 `JGY内容`：若展示NASA POWER历史气象，需匹配该目录内的来源文件。它是历史网格产品，单独保留来源身份。

放好文件再运行安装脚本，或明确指定路径：

```powershell
.\server\setup_windows.ps1 -Snapshot 'E:\共享资料\data-v1.0.db' -RawRoot 'E:\共享资料\raw' -TeamRoot 'E:\共享资料\JGY内容'
```

路径是示例，需替换为本机真实位置。导入器按内容哈希重新定位，保留原文件名和原导入版本关系，不猜测缺失数据。未提供 TeamRoot 时不把历史网格气象当现场实测补入。冻结有效监测424988条；全部原始监测476215条、9样品81项化学检测保留。tree_age=3仍标为按2023种植年份推算的“约3年”，不是精确测定树龄。

已有库迁移后的文件路径失效时，先运行 `data_pipeline/relink_sources.py --root '<实际raw目录>'` 预览，再加 `--apply`，它会先备份并按唯一哈希重连。不要重新导入已冻结来源。

## 启动

开发者工具与后端在同一电脑：

```powershell
.\server\start_demo.ps1
```

默认只绑定127.0.0.1:5000。若配置指向本机8001且该端口没有服务，脚本询问是否启动MOCK；显式 `-StartMock` 才可不交互启动。MOCK为规则联调服务，问答保留醒目标记。已有远程地址不会被替换成mock。`-NonInteractive` 不提示、不自动启用mock。

手机预览需要电脑和手机在同一可信局域网：

```powershell
.\server\start_demo.ps1 -BindAddress 0.0.0.0
```

脚本打印电脑局域网IP；仅在可信局域网放行端口5000。前台窗口按Ctrl+C停止；脚本只关闭它自己启动的mock进程。不要关闭他人服务。

## 演示流程

按 [演示流程](演示流程.md) 六步进行。最近N天使用最后有效历史数据，非当前实时监测。情景默认历史监测窗口起点；HYDRUS含初态和第7天终态，日期按实际返回显示。未核验雨量累计方式时仍保留0降雨等模型假设。回放保持原案例日期与地块，不改写成当前基地新计算。

## 常见问题

错误码详见 [错误码与降级](错误码与降级.md)。E_EVIDENCE_DOWN需检查蔡服务的网络地址、启动状态和令牌；仅HTTP200不代表真实服务通过。E_DATA_EMPTY需检查选择参数、来源和实际数据日期。参数未进入模型或工具失败时不展示数值差值，不把fallback作为成功依据。

重置录屏环境前先停后端，在 backend 运行：

```powershell
.\tools\reset_demo.ps1
.\tools\reset_demo.ps1 -Apply
```

第一条只预览。第二条先备份当前库、导出本轮轨迹，将旧runtime和旧库归档到仓库实验资料/07_实验结果/demo_reset，再恢复冻结快照；没有递归删除。非默认服务端口要加 `-ServicePort <端口>`。有服务在运行、路径越界/重叠、快照或原文件缺失会拒绝。恢复后再次启动并运行selfcheck；真实服务缺失仍会FAIL，不能为了录屏改为PASS。

归档含真实数据和轨迹，按团队数据共享范围保管，不随源码包上传。若需恢复，停止后端后使用归档中的before_reset.db和runtime；先备份当前状态，勿覆盖唯一副本。

## 安全说明

**业务服务无鉴权，仅限可信局域网。** 蔡服务的Bearer令牌只保护远程模型调用，不为Flask接口提供用户鉴权。禁止使用cpolar/ngrok等公网隧道暴露当前服务；演示结束关闭后端。不开debug、不共享.env，不执行模型生成的命令或路径。正式测试资料目录始终隔离，不导入、不读取、不打包。

## 第二轮界面模式

默认用户模式只显示业务数据、操作及缺条件追问；离线仍有重试。工作台顶部基地名连续点击5次切换开发者模式，再点5次返回（间隔超过1.6秒重计）。切换无弹窗，保存到本机storage；开发者模式查看mock状态、来源、档案参考值说明、处理轨迹、模型假设及原始累计降雨。模式只改变小程序显示，未改变接口验证状态或报告HTML；截图/录屏交接时需在交付登记中说明实际服务模式。
