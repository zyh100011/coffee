# 错误码与降级

所有HTTP错误响应带 `status=error, code, message, retryable, trace_id`。业务级工具失败保留统一工具结果；情景HTTP 200中的`status=failed`保留baseline/variant便于核查，额外带code/message/retryable/trace_id，差值与曲线为空。助手降级时保留事实块和`errors[]`，不会为了传输错误丢掉可用事实。

| 错误码 | 触发条件 | 前端提示 | 恢复动作 |
|---|---|---|---|
| E_PLOT_REQUIRED | 未选择或不存在地块 | 请选择当前地块 | 选择/录入地块 |
| E_PARAM_INVALID | 日期、范围、类型或单一变化校验失败 | 请核对输入条件 | 修改输入，重新确认 |
| E_TOOL_NOT_ALLOWED | 非白名单工具 | 工具请求未被允许 | 更换问题，核查route契约 |
| E_HYDRUS_TIMEOUT | 引擎或共享预算耗尽 | 计算超时，已保留输入，可重试或改用历史结果 | 重试；回放必须重新确认历史条件 |
| E_HYDRUS_FAILED | 输出解析、参数核验、收敛等失败 | HYDRUS计算失败，请查看原因 | 核查输入/日志；可转回放 |
| E_HYDRUS_UNAVAILABLE | EXE不存在或系统不可运行 | HYDRUS引擎不可用，可使用历史回放 | 提供合法引擎；转回放 |
| E_EVIDENCE_TIMEOUT | route/answer超时 | 本地循证服务超时，可重试 | 重试或农情直接查询 |
| E_EVIDENCE_DOWN | 服务未连接或HTTP错误 | 智能解释暂不可用，可直接查询农情 | 启动本地服务；保留已有事实 |
| E_EVIDENCE_INVALID | 服务响应契约错误 | 循证服务响应格式不符 | 核对蔡的接口契约 |
| E_EVIDENCE_NOT_FOUND | 证据/报告不存在或跨地块 | 证据未找到，该主张未核验 | 核对地块及证据ID |
| E_DATA_EMPTY | 无观测/无有效值/无历史结果 | 该地块暂无已入库的数据 | 完成确认映射与入库，或换时间范围 |
| E_INTERNAL | 未处理异常 | 服务暂时出错，请重试 | 按trace_id查server/logs/backend.log |
| E_OFFLINE | 微信网络请求失败，仅前端 | 后端未连接，请检查电脑与手机在同一网络、BASE_URL是否正确 | 检查后端与可信局域网地址 |
| E_REQUEST_TIMEOUT | 微信端超时，仅前端 | 计算超时，已保留输入，可重试或改用历史结果 | 保留输入重试或重新确认回放 |

`retryable=true`才出现通用重试。情景总工具预算60秒，前端70秒留出传输时间；回放按额外灌溉量匹配已有案例，当前只有0/20mm，其他值无案例明确失败。失败时不展示差值，不把fallback变成证据。不自动静默切换live到replay，也不修改全局模式。

引擎输出日志位于运行目录；未处理异常写入有大小上限的backend.log，响应不回传异常字符串或堆栈。服务无鉴权，仅供本机/可信局域网演示。

测试覆盖每个计划错误码、HTTP内部异常脱敏、网络断开、微信超时、非白名单与重试行为。后端与前端分别保留扩展码E_EVIDENCE_INVALID/E_REQUEST_TIMEOUT，文案同表。
