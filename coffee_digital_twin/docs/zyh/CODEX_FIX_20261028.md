## 二、模拟运行中发现的问题

检查方式：把当前数据库复制到隔离环境，启动 Flask 后端和 `tools/mock_evidence_service.py`，执行各页面的真实 JS 请求，把 WXML/WXSS 渲染成 375px 宽手机画面截图（工作台、问答、农情、情景、模型结果、地块、地块编辑）。这不是微信开发者工具，个别原生控件外观会有出入，但字号、文字内容、数据流是真实的。

### 功能性问题（会让演示失败）

1. **首页和问答的主打问题“40cm 最近 7 天墒情”实际查不到。** 问答返回 `data_query：missing_input；该地块无已确认参数/深度`。原因有两个：
   - `services/tool_registry.py:163` 把 `query_soil_moisture` 固定成 `parameter='soil_moisture'`，但入库数据的参数名是 `soil_humidity_layer1_raw / layer2 / layer3`，深度是 0–15/15–30/30–45cm，库里没有 `soil_moisture` 和 40cm。
   - mock 把“最近 7 天”按今天（10-22～10-28）计算，监测数据最后一天是 2026-06-15，窗口里没有数据。
2. 缺条件追问显示的是英文字段名：“请补充：depth_cm、start、end”，快捷回复只有日期，没有深度选项。
3. 模型结果页 HYDRUS 指标直接显示英文键名：`classification_basis`、`infiltration_depth_cm`、`root_uptake_ratio`、`water_status`。
4. 情景页起始日期默认是今天（2026-10-28），这一天没有任何监测和降雨数据，模拟只能按 0 降雨假设。

### 你说的“字体大”

5. 根因是微信原生 `<button>`：默认 18px（约 36rpx）、加粗、宽度固定 184px。`app.wxss` 只给 `button` 设了 `min-height`，没有改字号、字重和宽度。所以快捷提问、农事记录/模型结果/历史报告、查询历史气象、生成报告、设为当前/编辑/农事记录这些按钮都显得又大又粗，而且长文字会被挤成两三行。
6. 页面标题重复：导航栏已经写“咖啡农事循证决策助手 / 农情查询 / 模型结果”，页面里又用 36rpx 粗体再写一遍。
