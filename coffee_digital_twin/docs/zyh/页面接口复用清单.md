## 公共件与绑定规则

- 沿用 `utils/storage.js::savePlotId/getPlotId`，storage key 为 `plotId`；不新增 currentPlotId。旧 latestTaskId 是全局缓存，后续不能代替任务/地块校核。
- 新版请求绑定当前 plot_id；GET query / POST body 缺值时由 request 封装补齐，地块管理 `/api/plot/*` 不自动注入（v2 T3.0 的优先规则）。task_id 仍为明确的模型任务标识。
- 每次运行生成 task_id，将 plot_id、时间范围和 parameter_version 关联到 model_tasks。目前表只有 plot_id/scenario/status/time，没有时间范围和参数版本列；后续按最小兼容迁移补充。
- 沿用 app.wxss、status-card、risk-badge、loading-panel、chart-card、request Promise 封装。图表新建 Canvas 2D line-chart，不使用空 ec-canvas。
- 工作台、问答、农情、情景为 tab；跨 tab 的问题先写 session.pendingQuestion，再 switchTab；其余页面 navigateTo。
- 模型不可用/缺数据时不画数值，不用 demo 补真实字段；页面依赖后端状态、来源和缺项。旧 risk/fusion 默认值在 T2.5 一并核查。
- 两个旧页面在保存后使用 redirectTo(index)，新版 index 为 tab 后也需改为 switchTab。
