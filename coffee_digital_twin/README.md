## 启动

在工程根目录PowerShell运行 `./server/start_backend.ps1`。本工程Python位于`.venv`，默认本机5000端口。在backend另开窗口运行 `../.venv/Scripts/python.exe tools/mock_evidence_service.py --port 8001` 可启动独立MOCK服务。微信开发者工具导入本工程miniprogram目录，编译刷新。

详见 [Phase3使用说明](docs/zyh/Phase3使用说明.md)、[Phase2使用说明](docs/zyh/Phase2使用说明.md)和[HYDRUS工具说明](docs/zyh/HYDRUS工具说明.md)。后端尚无鉴权，只用于本机或可信局域网演示。
