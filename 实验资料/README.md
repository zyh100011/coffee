# 实验资料使用说明

目录依据官方方案第 6.7 节，所有材料区分真实资料、文献、假设模拟和测试构造数据。负责分工见每个目录的 README。

## 张源皓后续放材料的位置

1. 监测原始导出（六份主要 CSV、六份补充导出）、IN-G10 LAI TXT、土壤报告，放在 `03_地块与监测数据/raw/`。保持原文件名、原值和原格式；可以用子文件夹分批次。不用先整理成统一列，也不要在 Excel 中另存导致设备 ID 丢精度。
2. 土壤/根区文献原文放在 `01_原始知识资料/A3_土壤根区/`，在 `01_原始知识资料/来源台账.csv` 每份原文登记一行。未知条件填“未知”，不要补造。
3. 从原文抽取的土壤参数记录在 `02_标准化知识语料/土壤字段映射表.csv`。数值目前全为空；明确实测/文献/推算、单位、深度、页码和适用条件。文献值不能自动作为当前地块实测值。
4. 缺失或尚待报告的数据登记到 `02_标准化知识语料/缺项表.csv`。
5. 自己提供的土壤开发题填写 `05_开发与训练资料/dev_soil_zyh.jsonl`；模板不是参考答案或审核题集。

放入 raw 只完成收集，**不会自动入库**。后续 T2.6 会根据实际文件生成字段映射草稿；你需要确认各列含义/单位、设备对应地块/深度、有效时间段及降雨是累计值还是增量值。只有已确认映射的文件才入库和对外查询。

## 盘点命令

在 PowerShell 中执行：

```powershell
Set-Location -LiteralPath 'E:\coffe model\coffee_competition_zyh\coffee_digital_twin\backend'
$env:PYTHONIOENCODING = 'utf-8'
..\.venv\Scripts\python.exe tools\inventory_assets.py
```

输出为 `03_地块与监测数据/资产清单.csv`，包含编码、大小、哈希、列名、前三行、时间范围和读取问题。控制台提示疑似重复/重叠。这一步不会改原始文件，不会清洗、去重或导入数据库。XLSX 读取所有工作表；日期范围按可识别的日期/时间列计算；损坏文件记录错误，不能把它当已确认数据。
